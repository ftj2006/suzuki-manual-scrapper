Dual Sensor Brake Support Control Module Removal and Installation
Do not drop or otherwise expose the dual sensor brake support control module to large shock. Any dual sensor brake support control module that has received large shock should be replaced.
When replacing dual sensor brake support control module, use new control module. If used one is installed, DTC (C1681) could be detected due to mismatch of each registration.
After replacing dual sensor brake support control module, perform
Dual Sensor Brake Support Control Module Aiming Adjustment:Dual Sensor Brake Support
and check DTC.
When dual sensor brake support control module is replaced, traffic sign recognition function is setting ON. When necessary, traffic sign recognition function is setting OFF by operation of user customization function in combination meter.
Removal
Check that ignition is “OFF”.
Remove dual sensor brake support control module cover (1) as follows.
Unhooking claws (2) of dual sensor brake support control module holder (3) using a flat-bladed screwdriver or the like.
Remove dual sensor brake support control module cover (1) from dual sensor brake support control module holder (2) by moving it in arrow direction.
Disconnect connector and remove dual sensor brake support control module (1) by pushing claws (2) in arrow direction all together.
Remove dual sensor brake support control module (1) from dual sensor brake support control module holder (2) by moving it in arrow direction.
Installation
Reverse removal procedure noting the following points.
Check that claws (1) of dual sensor brake support control module (2) fixed to the holder (3) securely.
After installation, check that dual sensor brake support control module is no looseness, wobble or abnormal noise.
After installation, perform
Dual Sensor Brake Support Control Module Aiming Adjustment:Dual Sensor Brake Support
.

Right after turning ON blind spot monitor system.

Blind Spot Monitor System Description
Blind spot monitor system has a blind spot monitor function and rear cross traffic alert function. This system tells the driver of presence of a vehicle diagonally in the rear not reflected in the door mirror.
At the time of lane change, for example, unexpected approaching vehicle is told to the driver through the indicator light in the door mirror and warning buzzer.
For detecting a vehicle diagonally in the rear, the system uses a millimeter wave (radio wave) radar device incorporated in blind spot monitor control module.
Blind spot monitor system consists of blind spot monitor control module (main), blind spot monitor control module (sub), blind spot monitor indicator light (right and left), combination meter, ECM, TCM (A/T model), BCM, ESP ® control module and lighting and turn signal switch.
Operation Description
Blind spot monitor function
When the blind spot monitor function detects a vehicle approaching laterally and from the rear on the neighboring lane, the system alerts the driver lighting blind spot monitor indicator light in the door mirror. Further, if turn signal switch is operated at that moment, blind spot monitor indicator light blinks and warning buzzer sounds to urge suspension of the lane change.
1.
Detecting area
Rear cross traffic alert function
When moving backward, if rear cross traffic alert function detects vehicle(s) approaching laterally from the rear, the system indicates alarm sign in the information display and sounds warning buzzer to assist the driver’s safe operation.
1.
Detecting area

Blind Spot Monitor Control Module Self-Diagnosis Function
Description
Blind spot monitor control module monitors conditions of the system components and circuits. When an abnormal condition in the system occurs, blind spot monitor control module performs control as follows.
Self-Diagnosis Function
Blind spot monitor control module has self-diagnosis function that stores DTC for abnormalities detected in blind spot monitor system. Stored DTCs remain in memory of blind spot monitor control module (main) unless they are cleared.
Warning Function
Blind spot monitor control module blinks blind spot monitor OFF indicator (1) and rear cross traffic alert OFF indicator (2) to warn the driver that a malfunction is detected or the system is disabled temporarily.
Right after setting ignition “ON”, blind spot monitor control module turns on the blind spot monitor OFF indicator and rear cross traffic alert OFF indicator. If no abnormality is detected, these indicator lights are turned off in about 2 seconds after setting ignition “ON”. If any faulty condition is found, blind spot monitor control module blinks blind spot monitor OFF indicator and rear cross traffic alert OFF indicator.
Fail-Safe Control
When any abnormality is found, blind spot monitor control module disables blind spot monitor control.
