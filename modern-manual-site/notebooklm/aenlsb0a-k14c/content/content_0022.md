## AENLSB0A9201003 - LED Headlight Description

LED Headlight Description
The LED headlight is composed of LED for low beam and high beam. The main components of LED headlight are LED, reflector, heat sink and LED control module, and have the following features.
With an LED headlight, light is dispersed evenly compared with a discharge headlight. Further, the brightness of LED is similar to the sunlight and illuminates frontward brightly.
[A]:
Brightness
[B]:
Luminous width
LED headlights do not have arc tube unlike discharge headlight and their useful life is longer and not affected by ON/OFF switching. Further, LED maintains stable luminance over long periods and offers advantages for maintenance too.
LED Headlight Control System
The LED headlight unit is comprised of LED (1), reflector (low-beam side (2) and high-beam side (3)), heat sink (4), HI/LO switching motor (5), movable shade (6), cooling fan (7) and LED control module (8).
LED Control Module
The LED control module is built into the headlight assembly, and performs the LED lighting On / Off control, LED disconnection detection and cooling fan On / Off control.
For headlight auto leveling model, if the LED control module detects a disconnection of the LED, it sends a disconnection detection signal to the headlight auto leveling control module. Furthermore, after detecting a failure of the cooling fan, the LED control module decreases the current supplied to the LED to keep the LED headlight lit.
Heat Sink
Using cooling fan, forcedly radiates heat generated in LED.
Cooling Fan
Restricts rise of temperature in LED control module and internal circuit.
High-Beam, Low-Beam Changeover Function
Low beam
When the lighting switch is LO, the HI/LO switching motor (4) does not operate. As the movable shade (1) is fixed in a position where light from the reflector (the high-beam side) (2) is blocked, the light passes through the reflector (the low-beam side) (3), forming a low beam optical axis.
High beam
When the lighting switch is HI, the HI/LO switching motor (4) operates, causing the movable shade (1) to tilt. The light then passes between the reflector (the low-beam side) (3) and the reflector (the high-beam side) (2), forming a high beam optical axis.
Self-Diagnosis Function (Headlight Auto Leveling Model)
When the LED and/or LED control module malfunctions, the LED headlight warning light (1) in the combination meter (2) comes on to warn the driver of the trouble.

## AENLSB0A9201004 - Headlight Auto Leveling System Description (Headlight Auto Leveling Model)

Headlight Auto Leveling System Description (Headlight Auto Leveling Model)
The headlight auto leveling system consists of the headlight auto leveling control module, headlight leveling actuator, rear vehicle height sensor, lighting switch and combination meter.
When the ignition is “ON”, the headlight auto leveling control module monitors the vehicle position based on the signals from the rear vehicle height sensor linked to the rear suspension.
The headlight auto leveling control module communicates with other control modules through CAN communication line.
For more details of CAN communication, refer to “Communication System Description” in Section 10H.
K14C model:
Headlight Auto Leveling Control
Auto leveling control when vehicle is stopped
When the same vehicle height is maintained for a specified time after the vehicle height is changed and the headlights are on, the headlight auto leveling control module drives the headlight leveling actuators to maintain the proper optical axis based on the vehicle height detected just before the headlights are on.
Auto leveling control when vehicle is in motion
When a constant speed drive at 30 km/h (19 mile/h) or higher on other than rough roads is detected for a specified time and the headlights are on, the headlight auto leveling control module drives the headlight leveling actuators to maintain the proper optical axis based on the vehicle height detected just before the headlights are on. When changes in the vehicle height are detected for a specified time, the headlight auto leveling control module judges that the vehicle is running on a rough road and stops the auto leveling control.
Headlight Auto Leveling System Initialization

Lighting System Self-Diagnosis Function
Lighting System
Self-diagnosis function
Lighting system is controlled by BCM based on signal from lighting and turn signal switch via CAN communication.
Lighting and turn signal switch has self-diagnosis function that stores DTC for abnormalities detected in the system. Stored DTC remains in memory of lighting and turn signal switch unless it is cleared.
BCM monitors conditions of lighting system components and its circuits. When an abnormal condition in the system occurs, DTC is stored in the memory of BCM. Stored DTC remains in memory of BCM unless it is cleared.
Fail-safe control
BCM performs fail-safe control when an abnormal communication with lighting switch is detected and turns on headlights (low beam), clearance lights and tail lights.
When BCM detects an abnormal condition of auto-on headlight sensor, it disables auto-on headlight control and enters fail-safe mode controlling the system as normal lighting system.
Headlight Auto Leveling System (Headlight Auto Leveling Model)
Self-diagnosis function
Headlight auto leveling system is controlled by headlight auto leveling control module.
Headlight auto leveling control module monitors conditions of components and its circuits. When an abnormal condition in the system occurs, DTC is stored in the memory of headlight auto leveling control module. Stored DTC remains in memory of headlight auto leveling control module unless it is cleared.
Warning function
Headlight auto leveling control module turns on the following warning light depending on the system to warn the driver that a malfunction is detected.
Malfunction of headlight auto leveling system: Headlight auto leveling warning light (1)
Malfunction of LED headlight system: LED headlight warning light (2)
Fail-safe control
Headlight auto leveling control module performs fail-safe control when an abnormal condition related to headlight auto leveling system is detected and stops headlight leveling actuator control to protect system.
