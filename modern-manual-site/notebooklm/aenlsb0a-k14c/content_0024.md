## AENLSB0A9500001 - Precautions for Working on Glass
Path: ./source-mirror/SWIFT_A2L310_A2L412_A2L414/xml/AENLSB0A/AENLSB0A9500001.xml

Content:
Precautions for Working on Glass
Precautions for Applying Primer
Primer has an important role to enhance adhesion effect of adhesive. Primer to use for body adhesive and that for glass adhesive are different. Use appropriate one. (Do not use gauze or nozzle used for one type for another.)
Put masking tape to instrument panel and other parts to protect them against primer.
Shake primer container well before opening it and apply primer evenly.
Do not apply primer to body surface where adhesive still remains.
If primer is attached to plastic parts or any place other than intended area by mistake, remove it immediately using white gasoline.
Refer to primer maker’s instruction for proper handling and drying time.
Precautions for Applying Adhesive
Install glass within 5 minutes after applying adhesive.
Adjust adhesive nozzle so that you can apply adhesive to “Shape of Adhesive” specified in section for installation of each glass.
If adhesive is attached to plastic parts or any place other than intended area by mistake, remove it immediately using white gasoline.
After applying adhesive to windshield, keep windows open when opening and closing door and do not apply any impact to the windshield until the adhesive is completely dry.
Do not drive the vehicle until the adhesive completely hardens.
Do not force the adhesive to dry using infrared light or the like.

Precautions for Working on Power Window
If you check the anti-pinching function with your finger or arm, you may get injured.
Do not check the anti-pinching function using a part of your body.
Neglecting of the following precautions may cause damage to anti-pinching system.
Do not apply large impact to power window regulator, such as by dropping it.
Do not pinch any object during initialization of power window.
Without initialization of power window, auto operation and anti-pinching function will not work correctly. Power window main switch has memorized fully closed position of door glass. If the following items are carried out, make the main switch memorize the door glass position performing initialization.
Replacing of door related parts such as power window regulator assembly, glass run, etc.
Replacing of power window main switch.
Shutting off of electric power for power window main switch such as battery removal, etc.

Content:
Anti-Pinching Function Description
The anti-pinching function stops and then reverses the rising door glass when a load exceeding the preset level is applied to the door glass due to pinching of something.
The anti-pinching function is effective in auto-up operation.
The condition of pinching is judged by CPU in power window main switch.
Reverse Operation Stroke of Anti-Pinching Function
If a load exceeding the preset level is applied to the door glass (1), the door glass reverses by approx. 220 mm (8.66 in.).
If the door glass is reached the fully open position before it opens approx. 220 mm (8.66 in.), the reverse operation is stopped.

## AENLSB0A9601002 - Deadlock System Description (If Equipped)

Outgoing references: none

Content:
Deadlock System Description (If Equipped)
The deadlock system prevents the door locks from being tampered with and unlocked when the system is activated using the key, transmitter, remote controller or driver door request switch.
Activation
The deadlock system is activated and all doors are locked when the driver door lock is turned twice in the locking direction within 3 seconds using the key.
The deadlock system is activated and all doors are locked when the remote controller’s lock button or the driver door request switch is pressed twice within 3 seconds.
Deactivation
The deadlock system is deactivated only for the driver door and the driver door is unlocked when the driver door lock is turned once in the unlocking direction using the key. When the driver door lock is turned twice in the unlocking direction, the system is deactivated for all doors and the doors are unlocked.
The deadlock system is deactivated only for the driver door and the driver door is unlocked when the remote controller’s lock button or the driver door request switch is pressed once. When the button or switch is pressed twice, the system is deactivated for all doors and the doors are unlocked.
